疎通確認（ping代わり）

指定したサイトへブラウザから接続し、応答があるかどうかと応答時間を確認するツールです。pingの代わりとして、ネットワークの疎通確認に使えます。

結果の出力

ご利用にあたって

  • このツールはブラウザの機能だけで動作します。ICMPの ping や traceroute は実行できません。
  • ポート単体の開閉確認はできません。確認できるのは、HTTP / HTTPS で応答するサイトのみです。
  • 表示される応答時間は HTTP での往復時間です。ICMP の ping とは値が少し異なりますが、疎通の目安として利用できます。
  • サイト側の設定によっては、実際には接続できていても「NG」と表示される場合があります。
